Положите сюда .bin прошивки ТМ-07 (как в CorrReader):

  TM-07_230176_v1.010105_2A23F66C_438D4EAA.bin

Ищем только метку версии: v1.010105
(префикс TM-07_230176_ не сравнивается с 0x0007).
Хвост 2A23F66C_438D4EAA — ЛКГ, пишется в 0x07B6 при заливке.

Каталоги (первый существующий + все найденные):
  TM07_FIRMWARE_DIR (переменная окружения)
  LAST VERSION/firmware   ← эта папка
  src/firmware
  src/data/firmware

Сюда же можно класть запасную копию «Номера корректоров.xlsx».
Рабочий реестр — шара:
  \\srv-fs\FileServer\Production\BD_Corrector\Инструкция по выпуску корректоров\Номера корректоров.xlsx
Локальная копия для Docker: data/serial/ (sync: scripts/sync-serial-xlsx.sh pull|push).
Серийники 300/400 сверяются с этой таблицей по номеру заказа.
