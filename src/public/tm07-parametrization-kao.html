Серийные номера (300 / 400)

Формат PPPYYMMNNN: 300 — корректор (п.3), 400 — комплекс (п.201); YY — год, MM — месяц, NNN — порядковый номер в месяце (с 001). Сейчас счётчик хранится локально в браузере; позже — Firebird.

Содержание заказа

Таблица параметров по карте регистров 50 («Параметризация (1).docx»). Эталон адресов: карта регистров ТМ-07 (Google Таблица).

  • Номер карты смотрите в идентификации прибора (0x11, ожидается 0x000B=50).
  • Колонка «№ п/п» в Google Таблице ≠ номер шага на этой странице; сверяйте по адресу HEX и define.
  • Ошибка Modbus 0x02 — нет holding по адресу в данной прошивке.
  • Версия ПО читается из регистра 0x0007. Файл .bin берётся из папки firmware/; при расхождении предлагается перепрошивка (0x2000 / 0x2002).

Перед записью параметров ключ доступа подставляется автоматически (настройки администратора).

Заполняйте только если адреса в вашем паспорте отличаются от таблицы по умолчанию.
