Счётчики выдачи (месяц)

Серийники выдаются только из БД (TM07_SERIAL_COUNTER + TM07_SERIAL_ISSUED). Excel больше не читается и не пишется. Следующий номер = LAST_SEQ + 1. Обнулите LAST_SEQ, чтобы начать месяц с …001. Повторный заказ получает уже выданный S/N из TM07_SERIAL_ISSUED.

Операторы и PIN

У каждого оператора свой PIN (хранится как hash в БД). Можно также задать в .env: BENCH_OPERATOR_PINS=Иванов:Иван:4567,Петров:Пётр:8901. Общий BENCH_OPERATOR_PIN — только запасной, если персонального ещё нет. Удаление оператора обнуляет ссылки в сессиях/событиях.
